# STM32 Learning Journey – From Beginner to Advanced

This repository contains my personal learning and training projects for STM32 microcontrollers.
The goal is to build strong practical experience and prepare professional training material for engineering students.

## 🎯 Objectives
- Build hands‑on experience with STM32 peripherals.
- Practice CubeMX configurations and embedded C coding.
- Document each lesson with notes, diagrams, and small projects.
- Prepare structured training material for university students and engineers.

## 📁 Repository Structure
- Each video has its own folder containing:
  - CubeMX + IDE project
  - Notes (Markdown)
  - Circuit diagram or simulation (Protuse - real projects)
  - Test results

This repository is updated continuously .
